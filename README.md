# STM32 FreeRTOS Sensor Project

## Overview
An embedded firmware project using STM32 and FreeRTOS to explore real-time task scheduling and sensor-data processing.

## Hardware
- STM32 microcontroller development board
- Sensor module (to be added)

## Software and Tools
- STM32CubeIDE
- Embedded C
- FreeRTOS
- Git and GitHub

## Planned Features
- FreeRTOS task creation and scheduling
- Sensor-data acquisition
- Inter-task communication using queues
- Task synchronization
- Debugging and testing

## Project Status
In development.
